# 출력 위치·파일명 규칙 (저장 단계에서 읽는다)

## 기본 출력 위치

1. 사용자가 출력 폴더나 파일명을 지정하면 그 위치와 이름을 따른다.
2. 지정이 없으면 원본 PDF와 같은 폴더에 `<원본파일명>.md`로 저장한다.
3. 같은 이름의 파일이 이미 있으면 덮어쓰지 말고 사용자에게 확인하거나 별도 이름을 제안한다.

## 과목별 자료 폴더를 사용하는 경우 (선택)

사용자가 과목별 자료 DB나 Obsidian 볼트에 저장해 달라고 요청한 경우에만 아래 자동 매칭을 사용한다. 과목별 폴더·수업계획서·Obsidian은 기본 변환의 필수 조건이 아니다.

1. **DB 루트**: 사용자가 지정한 자료 폴더를 사용한다. 사용자가 기존 DB를 찾아 달라고 했지만 경로를 주지 않았다면 현재 작업 폴더와 사용자가 허용한 주변 범위에서 `*_수업계획서.md`가 있는 폴더를 찾는다. 사용자 홈 전체나 다른 볼트를 임의로 탐색하지 않는다.
2. **과목 매칭**: DB 루트의 `*_수업계획서.md`에서 과목명·담당교수·강의 키워드를 확인하고 PDF 표지·본문과 대조한다. 확신이 서면 해당 과목 폴더에 저장한다. 애매하거나 새 과목이면 과목명·위치를 한 번 확인한다.
3. **DB가 없을 때**: 기본 출력 위치를 사용한다. 사용자가 명시한 출력 경로는 항상 우선한다.

### 기존 파일명 관행 따르기

- 폴더가 `NN_제목.md` 또는 `NN_유형_제목.md` 형식을 쓰면 가장 큰 번호에 1을 더한다. 새 과목 폴더에서 사용자가 이 형식을 요청했다면 `00`부터 시작한다.
- 유형 태그(강의·과제·실험·시험)는 기존 관행에 맞춰 필요할 때만 붙인다. 제목에 같은 뜻이 있으면 중복하지 않는다.
- 제목은 원본 파일명·표지에서 정한다. 기존 폴더가 자유 형식이면 번호 체계를 새로 강제하지 않는다.

## 이미지와 중간 산출물

- 보존할 그림이 있으면 출력 md와 같은 폴더의 `images/`에 저장한다.
- 그림 파일명은 `<최종md파일명에서확장자를뺀이름>__page_NNN_imgK.png`처럼 문서 제목을 접두어로 붙여 문서 간 충돌을 막는다.
- md의 이미지 링크는 출력 md 기준 상대 경로를 쓴다. 예: `./images/lecture01__page_002_img1.png`.
- 보존할 그림이 없으면 새 `images/` 폴더를 만들지 않는다. 다른 문서가 공유하는 기존 폴더는 삭제하지 않는다.
- 추출작업폴더는 최종 출력과 구분한다. `pages/`·`text/`·후보 `images/`·`classification.json`은 7단계 표본 재검토가 끝날 때까지 보존한다.
