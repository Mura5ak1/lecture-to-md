# 검증 세부 (6·7단계 보충)

SKILL.md 6단계의 종료 코드 의미와 7단계의 필수 원칙은 항상 적용된다. 아래는 세부 항목과 스캔본 표본 규칙이다.

## 6단계 — 검증기 세부

종료 코드는 세 가지다:

- **0 PASS** — 구조 문제 없음, 내용 손실 의심 페이지 없음.
- **1 FAIL** — 구조 문제. 지적된 내용을 고치고 다시 실행한다. 검사 항목: frontmatter 키·빈 값·`총페이지`와 manifest 일치, 페이지 앵커 누락·중복·순서·빈 섹션, 이미지 링크 깨짐·빈 alt·미참조 파일(4단계에서 폐기한 후보는 `images/`에 복사되지 않으므로 대상 아님), 표 열 개수 불일치·구분행 누락, LaTeX `$`/`$$`/중괄호 짝, `TODO` 잔재와 "중략·이하 생략" 같은 요약 표현(원문 슬라이드에 실제로 있는 문구는 제외). 우발적 링크(대상이 URL·`#앵커`·실제 파일이 아닌 `[x](y)`; 원문 텍스트라면 `\[x\](y)`로 이스케이프).
- **2 REVIEW** — 구조는 정상이지만, 텍스트 초안의 단어·숫자가 md에 빠진 페이지가 있다. 표시된 페이지는 **반드시 `render_file`을 열어 md와 대조**하고, 고치거나(누락 확인) 초안이 깨진 것이었음을 확인한다. 스스로 "괜찮아 보인다"고 넘기지 않는다. 이미지와 대조해 문제가 없음을 확인한 페이지는 `--ack 7,8,13`처럼 넘겨서 확인 완료로 기록한다(확인하지 않은 페이지를 ack하지 않는다). 검증기를 통과시키려고 원문에 없는 텍스트를 md에 넣는 것은 금지다 — 오탐이면 ack로 처리한다. 텍스트 레이어가 없는 페이지(스캔본)는 기계 검사가 불가능하다고 따로 출력되므로 눈으로 확인한다.

**PASS(0)가 나올 때까지, 또는 REVIEW 페이지를 전부 눈으로 확인하기 전까지 다음 단계로 넘어가지 않는다.** 이 검사는 경보기일 뿐 증명이 아니다 — 경고가 없다고 원문과 일치한다는 뜻은 아니므로 7단계는 여전히 필수다.

## 7단계 — 표본 재검토 세부

6단계는 텍스트 초안 대비 단어·숫자 누락만 잡을 뿐 "원문과 md 내용이 실제로 일치하는가"는 확인하지 못한다. 숫자를 잘못 옮기거나 문장이 왜곡된 경우, 표 셀이 뒤바뀐 경우는 통과할 수 있다. 특히 2단계에서 `pure_text`로 분류돼 `render_file`을 한 번도 열어보지 않고 넘어간 페이지들은 지금까지 아무도 눈으로 대조하지 않은 상태다. 이 단계는 전체를 처음부터 다시 훑는 대신, 오류가 있을 확률이 높은 페이지를 골라 표본 재검토한다. **문서 크기와 무관하게 매번 반드시 수행한다.**

0. **스캔본(`SCAN-LIKE DOCUMENT`)이면 표본의 대상이 다르다.** `pure_text`가 하나도 없어 아래 1번이 빈 표본이 되므로, 이 단계를 건너뛰지 말고 전체 페이지에서 `max(3, 전체의 20%)`(최대 20)페이지를 뽑는다. 표·수식·손글씨·순수 텍스트가 모두 표본에 포함되게 유형을 섞고, 글자가 가장 많은 페이지와 숫자가 많은 표를 우선한다. 이미 3단계에서 한 번 읽었더라도 표본은 md의 해당 `## [p.N]` 블록을 이미지와 다시 처음부터 문장·숫자 단위로 대조한다. 오류가 하나라도 나오면 같은 유형의 페이지를 전부 확대 검증한다.
1. **표본 뽑기**: `classification.json`에서 `pure_text` 페이지들을 `risk_score` 내림차순으로 정렬해 (6단계의 `validation_report.json`에서 `recall`이 낮은 페이지가 있으면 그 페이지들을 먼저 포함시킨다) 상위 `min(전체 페이지 수의 15%, 20페이지)`개를 표본으로 뽑는다. (동점이면 `char_count`가 큰 쪽을 우선한다.)
2. **표본 재대조**: 뽑힌 각 페이지의 `render_file`을 이미지 열람 도구로 다시 열어서, 이미 작성된 md의 해당 `## [p.N]` 블록과 문장 단위로 대조한다 — 3단계와 같은 기준(누락 없는지, 숫자·용어가 정확한지)으로 확인한다.
3. **표/수식/그림 페이지(`needs_image`)는 가볍게만**: 이 페이지들은 3~4단계에서 이미 한 번 이미지로 대조했으므로 전체를 다시 옮기지 않는다. md의 표 셀 수·수식 개수·이미지 참조 개수가 render 페이지와 맞는지 개수 단위로만 빠르게 확인한다.
4. **불일치 발견 시 확대 검증**: 표본에서 실제 오류(누락, 오탈자성 왜곡, 잘못 옮긴 숫자 등)가 하나라도 나오면, 그 오류와 같은 신호(예: `weak_table_or_math_signal`)를 가진 `pure_text` 페이지 전체를 추가로 훑는다 — 표본에서 문제가 나왔다는 건 같은 유형의 다른 페이지에도 문제가 있을 가능성이 높다는 뜻이다. 표본이 전부 깨끗하면 확대 없이 종료한다.
5. **보고**: 몇 페이지를 표본으로 확인했고 몇 건을 수정했는지 사용자에게 짧게 보고한다 (예: "7단계: 18페이지 표본 재검토, 2건 수정"). 발견된 오류는 그 자리에서 바로 md에 반영한다.
