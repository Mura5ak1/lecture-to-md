## [p.1] 디지털 신호처리 개론

### 1.1 정의

디지털 신호처리(DSP)는 아날로그 신호를 디지털 형태로 변환하여
컴퓨터로 처리하는 기술 분야이다. 대표적인 응용 분야로는 음성 인식,
영상 처리, 통신 시스템 등이 있다.

핵심 개념: 표본화(Sampling), 양자화(Quantization), 부호화(Coding)

## [p.2] 1.2 표본화 정리 (Nyquist Theorem)

$$f_s \geq 2 f_{max}$$

여기서 $f_s$는 표본화 주파수, $f_{max}$는 신호의 최대 주파수 성분이다.
이 조건을 만족하지 않으면 앨리어싱(aliasing)이 발생한다.

**표 1-1. 표본화 주파수 비교**

| 구분 | 표본화주파수 | 응용분야 |
|---|---|---|
| 전화 | 8 kHz | 음성통화 |
| CD음질 | 44.1 kHz | 음악재생 |
| 초음파 | 1 MHz 이상 | 의료영상 |

## [p.3] 1.3 필터의 종류

저역통과필터(LPF), 고역통과필터(HPF), 대역통과필터(BPF)가 있으며
각각의 전달함수는 다음과 같이 표현된다.

$$H(z) = \frac{1 - z^{-1}}{1 - a z^{-1}}$$

## 이 예시에서 지킨 규칙

- 실제 변환에서는 문장을 원본 그대로 옮기고 순서를 바꾸지 않는다 (요약하지 않음).
- 페이지 앵커(`## [p.N]`)는 반드시 페이지 번호 순서대로, 빠짐없이 등장한다.
- 원본 텍스트의 소제목(예: "1.1 정의")은 `###`로, 페이지 대표 제목은 `##`에 포함시켰다.
- 표는 원본의 정렬을 그대로 마크다운 표 문법으로 옮겼다.
- 수식은 눈으로 보이는 그대로 LaTeX로 옮겼다 (변수명, 위첨자/아래첨자 포함).
- **형태 자체가 정보인 그림(p.3의 그래프)**은 실제 이미지 파일을 참조하며, alt 텍스트에 원본 캡션(있다면)과 내용 설명을 함께 넣어 검색 가능하게 했다.
- **텍스트로 완전히 대체 가능한 이미지(p.4의 UI 스크린샷)**는 파일로 남기지 않고, 담긴 정보(메뉴명·링크·주소)를 문장으로 그대로 옮겼다.
